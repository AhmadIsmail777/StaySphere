Storing Passwords
We Never store the Passwords as it is. We store their hashed form

For every input, there is a fixed output
They are one-way functions: we can't get input from output(eg modulus and % type of function)
Output length is fixed for different input data & varying length
Small changes in input should bring large changes in output.
eg of hashing function --> SHA256 , MD5 , CRC , becrypt
pbkdf2 is the hasing algo which used in this project

Salting
Password salting is a technique to protect passwords 
stored in databases by adding a string of 32 or more 
characters and then hashing them.
